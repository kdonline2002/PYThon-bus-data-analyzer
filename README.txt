Business Data Analyzer
Version 1.0

----------------------------------------
QUICK START
----------------------------------------

1. Install Python 3.10 or later
   https://www.python.org/downloads/

IMPORTANT:
Tick "Add Python to PATH" during install.

2. Extract this folder

3. Double-click:
   run_app.bat

4. The app will open in your browser

----------------------------------------
FIRST RUN
----------------------------------------

The first launch may take several minutes while dependencies install.

----------------------------------------
DEMO MODE
----------------------------------------

The application includes:
- Sales demo
- Inventory demo
- Customer + product master demo

Use the "Load Demo" option inside the app.

----------------------------------------
TROUBLESHOOTING
----------------------------------------

If browser does not open:
Go to:
http://localhost:8501

If launch fails:
- Ensure Python is installed
- Restart the application
- Re-run run_app.bat
